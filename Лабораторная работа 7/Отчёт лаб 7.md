# Лабораторная работа №7. Классификация на основе признаков

## Исходные данные

Фраза: `ОСЫ ЖҰМСАҚ ФРАНЦУЗ ОРАМДАРЫН КӨБІРЕК ЖЕП ШАЙ ІШІҢІЗ`

Строка для сравнения без пробелов: `ОСЫЖҰМСАҚФРАНЦУЗОРАМДАРЫНКӨБІРЕКЖЕПШАЙІШІҢІЗ`

Алфавит: `АӘБВГҒДЕЁЖЗИЙКҚЛМНҢОӨПРСТУҰҮФХҺЦЧШЩЪЫІЬЭЮЯ`

Шрифт: `Times New Roman`, исходный размер `14`, экспериментальный размер `18`.

## Выполнение задания

1. Расчет меры близости изображений символов реализован на основе признаков из лабораторной работы №5: массы, координат центра тяжести и осевых моментов инерции. Перед сравнением признаки приводятся к нормированному виду, затем вычисляется евклидово расстояние `d`; мера близости вычисляется как `S = 1 / (1 + d)`.

2. Для каждого обнаруженного символа строки рассчитана мера близости со всеми символами выбранного алфавита. Для каждого сегмента получен полный список гипотез, отсортированный по убыванию меры близости.

3. Гипотезы записаны в файл `output/hypotheses.txt` в формате, аналогичном `List[Tuple]`: номер символа, затем список пар `(символ, мера близости)`. Для удобства первые 10 гипотез также сохранены в табличном виде в `output/top_hypotheses.csv`.

4. Лучшие гипотезы, то есть первые элементы отсортированных списков, объединены в распознанную строку. Эта строка сохранена в `output/recognized.txt` и приведена ниже в разделе результата.

5. Распознанная строка сравнивается с исходной строкой без пробелов. По результатам сравнения вычислены количество ошибок и доля верно распознанных символов.

6. Для эксперимента сгенерирована та же строка с размером шрифта `18` вместо исходного `14`. Результаты эксперимента сохранены в каталоге `output/experiment/` и приведены в отдельном разделе.
